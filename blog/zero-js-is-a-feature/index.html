Why zero JavaScript is a feature

October 23, 2026 · 1 min read

On this page
  • The cost you don't see
  • What content sites actually need
  • Measuring it

The cost you don't see

Every kilobyte of JavaScript is downloaded, parsed, compiled and executed before a page becomes fully responsive. On a mid-range phone that cost shows up directly in Interaction to Next Paint.

What content sites actually need

Most pages of a blog, docs site or marketing site are text, images and links. HTML already does that perfectly. The few interactive parts, such as search, a copy button or a calculator, can be islands that load on their own.

Measuring it

The home page runs a live meter that shows its own transfer size, JavaScript weight and Largest Contentful Paint in your browser. Then try the 1.0 release notes to see what keeps those numbers low over time.
