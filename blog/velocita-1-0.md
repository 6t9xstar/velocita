# Velocita 1.0 is here

> Starter templates, one-command deploys, a performance budget and a Lighthouse CI gate. Here is what shipped in 1.0.

## What's new

Velocita 1.0 completes the road from "fast by default" to "stays fast in production":

- **Starter templates** for a blog, docs and a local business, each scoring Lighthouse 100 in every category
- **`velocita deploy`** for Cloudflare Pages, Netlify, Vercel and GitHub Pages
- **`velocita check`**, a browser-free performance budget that runs in milliseconds
- **A Lighthouse CI gate** written for you, failing CI below 95

## Why a budget matters

Sites rarely start slow; they get slow one dependency at a time. A budget that runs on every build turns "we should keep it fast" into a failing check. Read more in [why zero JavaScript is a feature](/blog/zero-js-is-a-feature/).
