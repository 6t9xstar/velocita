Why Velocita

Everything other frameworks leave to plugins

Performance, SEO and AI discoverability aren't add-ons here. They're the defaults, and the build fails before a regression ships.

⚡

Zero JavaScript by default

Pages ship HTML and ~3 KB of inlined CSS. No framework runtime, no hydration, nothing to block the main thread.

🔎

SEO that is impossible to forget

Canonical, Open Graph, JSON-LD, sitemap, hreflang and RSS on every page. A build-time linter catches the rest.

🤖

Built for AI search (GEO)

llms.txt, llms-full.txt and a clean Markdown copy of every page, plus a one-line AI-crawler policy.

🏝️

Islands when you need them

Drop in an interactive component; only that page loads it, and only when it scrolls into view.

🖼️

Images and social cards

Automatic width/height, WebP srcset, LCP priority hints and a 1200×630 OG card for every page.

🌍

Multilingual out of the box

content/hi/… becomes /hi/… with hreflang clusters, x-default, sitemap alternates and a language switcher.

Developer experience

Markdown in. Fast HTML out.

Write content in Markdown, or pull it from Contentful, Sanity or any JSON API. Layouts are plain JavaScript functions, with no template language to learn and nothing to compile.

Learn about layouts →
// layouts/post.js: a layout is just a function
export default ({ page, h }) => `
  <article>
    <h1>${h.escape(page.title)}</h1>
    <p>${h.date(page.date)} · ${page.readingTime} min</p>
    ${page.html}
  </article>`;

FAQ

Questions

Is Velocita really zero JavaScript?

Yes. Content pages ship only HTML and inlined CSS. JavaScript is added only to pages that contain an island, and each island loads only when needed.

Do I need to learn a template language?

No. Layouts are plain JavaScript functions that return HTML strings, and content is Markdown with frontmatter.

Can I use a headless CMS?

Yes. Built-in sources cover Contentful, Sanity and any JSON API, and a source is just an async function you can write yourself.

Where can I deploy?

Anywhere that serves static files. Velocita writes config for Cloudflare Pages, Netlify, Vercel and GitHub Pages.

What does it cost?

Nothing. Velocita is MIT licensed and has zero runtime dependencies.
