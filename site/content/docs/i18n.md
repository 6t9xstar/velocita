## Configure locales

```js
export default {
  lang: 'en',
  locales: ['en', 'hi'],
  nav: { en: [/* … */], hi: [/* … */] },
};
```

## Add translations

`content/about.md` and `content/hi/about.md` are linked as translations automatically. For different file names, give both the same `translationKey`.

Every translated page gets `hreflang` tags with `x-default`, sitemap alternates, the right `<html lang>`, and a switcher in the header. Feeds and search work per language.

Last step: [deploy your site](/docs/deploy/).
