layout: home
faq:
  - Is Velocita really zero JavaScript? :: Yes. Content pages ship only HTML and inlined CSS. JavaScript is added only to pages that contain an island, and each island loads only when needed.
  - Do I need to learn a template language? :: No. Layouts are plain JavaScript functions that return HTML strings, and content is Markdown with frontmatter.
  - Can I use a headless CMS? :: Yes. Built-in sources cover Contentful, Sanity and any JSON API, and a source is just an async function you can write yourself.
  - Where can I deploy? :: Anywhere that serves static files. Velocita writes config for Cloudflare Pages, Netlify, Vercel and GitHub Pages.
  - What does it cost? :: Nothing. Velocita is MIT licensed and has zero runtime dependencies.
