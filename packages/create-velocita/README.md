# create-velocita

Scaffold a new [Velocita](https://github.com/6t9xstar/velocita) site.

```sh
npm create velocita@latest my-site
npm create velocita@latest my-site -- --template docs --title "Acme Docs"
pnpm create velocita my-site
bun create velocita my-site
```

Templates: `blog`, `docs`, `business`. With no arguments in a terminal, it asks for the folder and template.
