# velocita-theme-paper

A calm, serif reading theme for [Velocita](https://github.com/6t9xstar/velocita), with warm colours, dark mode and card-style list pages.

```sh
npm install velocita-theme-paper
```

```js
// velocita.config.js
export default { theme: 'velocita-theme-paper' };
```

Your own `css` and `layouts/` still override anything the theme sets.
